# Exercise Library and Demo Videos

The **Exercises** tab is your gym's exercise library. Coaches pick from it when they build a program. Every gym starts with a set of **default** exercises, named equipment first, such as *Barbell Bench*. You can add your own (**Custom**) exercises too.

Any coach can add exercises, archive them and add videos.

:::note Beta
Training is marked **Beta** in the app, so things may change.
:::

---

## Finding Exercises

Go to **Add-ons → Training → Exercises**.

- **Search exercises** by name, muscle group or equipment.
- Use the **Active**, **Archived** and **All** chips.
- Use the source menu: **All sources**, **Default** or **Custom**.
- Sort by name, muscle group or equipment.

---

## Adding an Exercise

1. Click **Add exercise**.
2. In **Add your own exercise**, enter the **Exercise name**, naming it equipment first like the defaults. You can also add the **Muscle group** and **Equipment**.
3. Click **Add exercise**.

If the name is already in your library, you'll see **Another exercise already has this name**. If an exercise with that name was archived, it's restored instead.

You can also add an exercise straight from the program builder's picker with **+ Add custom exercise**.

Exercises can't be renamed or deleted. Archive one you no longer want.

---

## Archiving

Open an exercise's **⋯** menu and click **Archive**. The exercise is hidden from the exercise picker, but programs and logs that already use it keep it. Click **Restore** to bring it back.

---

## Default Lift

If you use [training maxes](training-maxes.md), open **⋯ → Default lift…** to choose the lift this exercise is usually **Based on**, and a **Multiplier**. When a coach adds the exercise to a program, the row starts out based on that lift. Rows already in programs don't change.

---

## Demo Videos

Each exercise can have **one** demo video: either a file you upload or a YouTube link. It plays:

- on the **Exercises** tab
- in the program builder (**Play video**)
- on the member's workout card on My Training (**Watch demo**)

### Adding a video

1. Open the exercise's **⋯** menu and click **Add video**.
2. Choose one:
   - **Paste a YouTube link:** paste a youtube.com or youtu.be link (Shorts work too) and click **Save link**. YouTube links use none of your storage.
   - **Upload a file:** choose an MP4, MOV, M4V or WebM file of up to 750 MB, and click **Upload**.

If you only see the YouTube link box, file uploads aren't available, so use a YouTube link.

While a file uploads, you see its progress, then *Checking the video…*. The upload keeps going if you close the box, but **stay on the page** until it finishes. Only one upload runs at a time.

The upload box also shows how much of your gym's video storage is used.

:::tip iPhone videos
On iPhone, set **Settings → Camera → Formats → Most Compatible** so your videos play everywhere.
:::

### Replacing or removing a video

The **⋯** menu also has:

- **Play video**
- **Replace video**: the current video stays until the new one finishes uploading
- **Remove video**: coaches and members no longer see it, and the exercise stays in your library
