# Event Registration

The **Event Registration** report allows you to view registrations for your events, see who has signed up, and manually add attendees.

---

## How to Use

1. Select an **Event** from the dropdown to view its registrations.
2. The report shows all registered attendees with their details.

---

## Manual Registration

You can manually register members for events from this report:
1. Search for a member by name or email
2. Select the member from the dropdown
3. Choose a ticket type (or leave as "No ticket" for free/comp)
4. Set the number of tickets
5. Choose a **Payment** option:
   - **Mark Unpaid** — Register the member now and collect payment at a later date
   - **Charge Card on File** — Immediately charge the member's saved payment method
   - **Mark Paid (Cash)** — Record that payment was already collected in cash
6. Optionally check **Comp** to register with no charge
7. Answer any required event questions
8. Click **Add Registration** to complete

---

## Editing a Registration

You can edit the answers on an existing registration directly from the report:

1. Find the registration in the list
2. Click the **Edit** button in the Actions column
3. The Answers column will switch to inline editing mode, showing dropdowns, checkboxes, or text fields matching the original question types
4. Make your changes
5. Click **Save** to update, or **Cancel** to discard changes

This is useful for correcting division selections, fixing typos, or updating answers without deleting and re-creating the registration.

---

## Deleting a Registration

To remove a registration (e.g., duplicates or incorrect entries):

1. Click the **Delete** button in the Actions column
2. Confirm the deletion when prompted

:::caution
Deleting a registration is permanent and cannot be undone. This does not automatically issue a refund — handle refunds separately if needed.
:::

---

## Location Filter

If multi-location is enabled, you can filter events by location.
