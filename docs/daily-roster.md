# Daily Roster

The daily roster is a **read-only display screen** that shows who is expected and who has arrived today. It's designed to sit in a browser tab on a front-desk tablet, right alongside the <a href="/docs/kiosk">kiosk</a>. It is always located at yourdomain.managememberships.com/kiosk/roster — you can also open it from the admin area under **Reports → Bookings → Daily Roster** (it opens in a new tab).

The page **refreshes automatically every 10 seconds**, so it always reflects the latest signups and check-ins with no interaction required.

---

## What It Shows

The screen is split into two sections:

### Today's Classes
Every class happening today, grouped by class and time slot, with everyone who signed up in advance listed underneath. Next to each name you'll see:

- Their **membership level**
- How many times they've **checked in this week** (e.g. "3x this week")

### General Check-Ins
Members who checked in at the kiosk **without selecting a class** — open gym visits, general attendance, etc. Each entry shows the member's membership level, weekly check-in count, and the time they arrived.

---

## Check-In Status

Names under a class can appear three ways:

| Display | Meaning |
|---------|---------|
| Name only | Signed up in advance, hasn't checked in yet |
| Name + green check | Signed up in advance **and** checked in |
| Name + green check + **WALK-IN** badge | Checked in for the class at the kiosk **without signing up in advance** |

A **walk-in** is someone who showed up and checked into a class without a prior registration. They appear under the class they checked into, marked with an amber "Walk-in" badge, so staff can see at a glance who registered ahead of time versus who dropped in.

If nobody pre-registered for a class but someone walks in for it, the class still appears on the roster with that person listed under it.

---

## Password Protection (Optional)

You can require a password before the roster can be viewed — useful if the tablet is somewhere members might wander past.

1. Go to **Settings → Portal Settings**
2. Find the **Daily Roster Password** field (right below the Kiosk Password)
3. Set a password and save

Leave the field blank for no password. The roster password is **separate from the kiosk password**, so you can protect one without the other. Once unlocked on a device, the roster stays unlocked for that browser session.
